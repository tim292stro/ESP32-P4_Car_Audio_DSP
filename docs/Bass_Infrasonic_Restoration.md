# Bass and Infrasonic Restoration

Back to the [root README](../README.md).

See also [Bypass Routing and Control](Bypass_Routing_and_Control.md), [Register Manual](Register_Manual.md), [Calibration Guide](Calibration_Guide.md), and [ESP32 Core Logic](ESP32_Core_Logic.md).

## Purpose

This document is the canonical reference for bass and infrasonic restoration behavior in the current firmware.

It covers:

- Bass and infrasonic restoration runtime behavior.
- Synthesis blend behavior (`subMix`, `infraMix`).
- Analysis and update cadence expectations.
- Room-compensation ordering relative to restoration and duck/sum stages.
- Host-visible controls and explicit non-ABI surfaces.

## Runtime Placement in the Primary Path

Per primary lane, the effective order is:

1. Primary gain and EQ.
2. Restoration synthesis branch (when enabled).
3. Room-compensation interaction on the restoration layer.
4. Add restoration contribution back to the lane program.
5. Primary ducking.
6. Primary and SFX summing.
7. Crossover stages.

This matches the current Core0 pipeline where restoration output is merged into `shapedPrimary` before ducking and before crossover processing.

## Host-Visible Restoration Controls (Current ABI)

Restoration processing is controlled by `MTR_PRIMARY_BYPASS_MASK` (`0x00A6`) per-lane bypass bits:

- Bits `[7:4]`: bass restoration bypass for `CH0..CH3`
  - `0`: bass restoration active.
  - `1`: bass restoration bypass.
- Bits `[11:8]`: infrasonic restoration bypass for `CH0..CH3`
  - `0`: infrasonic restoration active.
  - `1`: infrasonic restoration bypass.

Operational notes:

- Bass restoration bypass is evaluated per primary lane and gates entry to that lane's restoration branch.
- Infrasonic restoration only contributes when bass restoration is active and infrasonic bypass is not enabled for that lane.

## Restoration Model

The restoration branch is lane-local (4 independent primary lanes).

### Voice and Level Conditioning

For each lane:

- Envelope tracker and RMS tracker are updated from the lane program.
- Voice suppression check uses `voiceSensitivity`.
- A lane output gain scale is adapted toward target RMS using `targetRmsThresholdLinear`.

### Bass Restoration Synthesis

Bass restoration uses lane-specific target phase step `targetStepBass` and a smoothed phase-step state.

- Synthesis activates only when target step and voice checks pass.
- Output is sinusoidal and scaled by lane RMS and adaptive lane gain scale.

### Infrasonic Restoration Synthesis

Infrasonic restoration uses lane-specific `targetStepInfrasonic` with a slower smoothing constant.

- Infrasonic restoration only runs when the lane's `MTR_PRIMARY_BYPASS_MASK` infrasonic bypass bit is clear.
- If disabled, infrasonic restoration step state decays toward zero.

### Blend Model

The combined synthesis layer is:

- `total = (subharmonic * subMix) + (infrasonic * infraMix)`.

## Room Compensation Ordering

Room-compensation coefficients are applied to the restoration layer path, and the resulting compensation term is differenced from the raw synthesis layer before final lane injection.

- `MTR_PRIMARY_BYPASS_MASK` bits `[15:12]` control whether this compensation interaction runs per lane.
- The post-comp restoration contribution is then added into the lane program before ducking.

## Analysis and Update Cadence

Pitch/step targets are generated by Core1 side-path analysis and consumed by Core0 restoration synthesis.

### Analysis Path Rates

- Input side-path source: primary lanes (`CH0..CH3`) only.
- Decimation chain per lane:
  - `192000 Hz -> 24000 Hz` (decimate by 8).
  - `24000 Hz -> 3000 Hz` (decimate by 8).
- Valid analysis sample cadence: every 64 input samples (`192000 / 64 = 3000 Hz`).

### Target-Step Update Cadence

Pitch tracker correlation runs every 32 valid 3 kHz samples:

- Update rate: `3000 / 32 = 93.75 Hz`.
- Update period: about `10.67 ms`.

Each primary lane has independent tracker state and independent `targetStepBass`/`targetStepInfrasonic` atomics.

## ABI vs Non-ABI Surfaces

Current SPI ABI directly exposes restoration bypass gates via `MTR_PRIMARY_BYPASS_MASK` bits `[7:4]` and `[11:8]`.

The following restoration shaping parameters are runtime state and are not currently host-addressable in the canonical register map:

- `subMix`
- `infraMix`
- `voiceSensitivity`
- `targetRmsThresholdLinear`

If future tuning controls are added for these, they should be documented as new ABI features in [Register Manual](Register_Manual.md) first, then referenced here.
